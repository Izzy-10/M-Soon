## Site structure

```
index.html     Home: hero, the jobs, founder, contact
about.html     About the Mastermind
offer.html     Services: business websites and WhatsApp/AI bots
contact.html   Contact details and socials
privacy.html   Privacy policy
```

Plain HTML, CSS and a little JavaScript. No build step and no dependencies.

## Run locally

```bash
git clone https://github.com/Izzy-10/M-Soon.git
cd M-Soon
# open index.html in your browser
```

## Deploy

Hosted on Vercel as a static site: Framework Preset **Other**, no build command, no output directory. Every commit to `main` redeploys automatically.
